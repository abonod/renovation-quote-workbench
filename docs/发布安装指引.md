# 装修报价管理工作台 Skill — 发布与安装指引

## 一、发布包

- `renovation-quote-workbench-skill-v1.zip`：标准 Skill 分发包（含 SKILL.md + workbench/index.html + 本地库 + Excel 模板），根目录结构可直接被 Marvis 识别导入。

## 二、安装方式（给使用方）

方式 A：本地导入（推荐）
1. 将 ZIP 下载到使用方电脑并解压（或不解压直接给路径）。
2. 使用方在 Marvis 中打开「能力市场 → 安装外部 Skill」，选择该 ZIP 或解压后的 `renovation-quote-workbench` 目录。
3. 安装成功后，使用方的任意 Agent 即可通过技能加载该 Skill，或直接说“打开装修报价管理工作台”唤起。

方式 B：让使用方自己的 Agent 代装
1. 把 ZIP 路径/文件发给使用方。
2. 让使用方的 Agent 执行「安装外部 Skill」并指定该 ZIP 路径即可，无需人工操作。

## 三、使用说明

- 安装后打开 `workbench/index.html` 即为工作台（纯浏览器离线应用，不依赖网络与后端）。

- 第三方公司名不会内置，仅从导入的模板识别，模板见 `workbench/templates/装修报价模板.xlsx`。
